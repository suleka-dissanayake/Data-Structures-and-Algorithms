This repository contains coursework, practical exercises, and implementations developed during my **2nd Year, 1st Semester** as part of the **Bachelor of Science in Information Technology (BSc. in IT)** program at the **University of Vavuniya, Sri Lanka**.  
It focuses on mastering **Data Structures and Algorithms (DSA)** using **Java**, with a strong emphasis on manual implementations, algorithmic thinking, and problem-solving.
